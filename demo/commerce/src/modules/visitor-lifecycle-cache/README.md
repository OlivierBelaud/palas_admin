# Visitor lifecycle cache

Keep these cache entities outside `visitor-session`. In the pinned beta.12 loader, the first entity discovered in a module also takes the module's service alias. Putting a lifecycle fact before `VisitorSession` made `step.service.visitorSession` resolve to the fact service, so session identity filters were dropped and each event could read the entire fact table.

Entity names and SQL tables are unchanged. The regression test `tests/visitor-session-registration.test.ts` loads the actual module layout and checks the SQL generated by a session lookup.
